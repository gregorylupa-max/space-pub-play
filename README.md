# Space Pub

A cartoon arcade game set in a bar in outer space: pour drinks, slide them down the bars, catch the empty glasses and keep the customers happy. Easy to pick up, hard to master. For kids and grown-ups, alone or with a friend.

## ▶ Play now

**https://gregorylupa-max.github.io/space-pub-play/**

It runs in any modern browser on PC, tablet or phone, with nothing to install. You can play with the keyboard, a game controller or touch.

### 📱 Install it like an app

On a phone or tablet, open the link and choose **Add to Home Screen** (iPhone/iPad: the Share button; Android: the ⋮ menu → *Install app*). On a computer, Chrome and Edge show an **Install** icon in the address bar.
You get a Space Pub icon that opens full screen, and once it has loaded it plays even with no internet.

You can also download `index.html` and double-click it to play offline.
